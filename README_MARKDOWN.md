##### 個人用ポータルサイト(Personal portal site)
## 概要(overview)
個人用のポータルサイトで、軽量でほとんどのブラウザで使えます。(It is a personal portal site that is lightweight and compatible with most browsers.)
## 主な機能(Key Features)
- URLに転送(Redirect to URL)
- 登録しているサービス名を検索(Search for the name of a registered service)
- Google検索(Google Search)
- 各リンクへの転送(Redirect to each link)
- PWA機能(PWA Features)
